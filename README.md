Overview

Lab System is a web-based laboratory management project designed to improve the organization and efficiency of clinical laboratory workflows.

The system aims to provide a centralized environment for managing patient information, laboratory requests, specimens, test results, and reports.

Its goal is to reduce manual processes, improve information management, and support a more structured laboratory workflow.

Core Modules
Patient Management — Organize patient information and laboratory records.
Test Management — Manage laboratory test requests and examinations.
Specimen Management — Record and track laboratory specimens.
Results Management — Manage, review, and validate test results.
Report Generation — Prepare organized laboratory reports.
User Management — Manage user accounts and access permissions.
Dashboard — Provide an overview of laboratory activities.

These represent the proposed system capabilities and may not all be implemented yet.

Getting Started
Prerequisites
Node.js
npm
Git
Installation

Clone the repository:

bash
git clone https://github.com/SquartPOR1/Lab_System.git


Navigate to the frontend directory:

bash
cd Lab_System/frontend


Install dependencies:

bash
npm install


Start the development server:

bash
npm run dev


Open the local development URL provided in your terminal.
